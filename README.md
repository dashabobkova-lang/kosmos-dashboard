# KOSMOS dashboard

Автосборка дашборда `SALES REPORT WB KOSMOS.xlsx` из ежедневных отчётов WB,
которые сотрудник выкладывает в Битрикс24 (Общий диск → «ДАШБОРДЫ И ОТЧЕТЫ» →
«ежедневные отчеты КОСМОС» → папка `ДД.ММ.ГГ`).

## Расписание

| МСК | UTC (cron) | Что делает |
|-----|-----------|------------|
| 09:00 | `0 6 * * *` | основная сборка + сводка в Telegram |
| 10:30 | `30 7 * * *` | перепроверка: если WB дозаписал заказы за вчера — пересборка и исправленная сводка |

Запуск вручную — вкладка Actions → KOSMOS dashboard → Run workflow.

## Секреты репозитория

`Settings → Secrets and variables → Actions`:

| Имя | Значение |
|-----|----------|
| `BITRIX_WEBHOOK` | `https://bylulu.bitrix24.ru/rest/<id>/<token>` — входящий вебхук |
| `TG_TOKEN` | токен Telegram-бота |
| `TG_CHAT` | id группы |

## Файлы

- `build_kosmos_dashboard.py` — чтение отчётов из Битрикса, сборка xlsx, заливка, Telegram
- `daily.py` — логика одного запуска: слать сводку или молчать
- `state.json` — какие итоги за какой день уже отправлены (коммитится ботом автоматически)

## Почему сводок не бывает две

`daily.py` сравнивает итоги за вчера с `state.json`:

- записи нет → сборка + обычная сводка
- запись есть, цифры совпали → ничего не делает
- запись есть, цифры разошлись → пересборка + сводка с пометкой «исправленная»

Если отчёт за вчера ещё не выложен — скрипт просто выходит и ждёт следующего запуска.
При любом сбое в группу приходит «⚠️ Дашборд КОСМОС не собрался» со ссылкой на лог.
